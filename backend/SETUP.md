# Подключение номеров участников и админки (5 минут, один раз)

Заявки сохраняются в Google Таблицу и получают номер участника («Участник #7» в Telegram и на пропуске).
Админка `/admin` показывает их в реальном времени и выгружает в Excel.

1. Создайте Google Таблицу (sheets.new), назовите «Участники Cyber Fest».
2. **Расширения → Apps Script**. Удалите всё, вставьте код из `backend/Code.gs`.
3. В функции `setup()` замените `ПРИДУМАЙТЕ_ПАРОЛЬ` на свой пароль админки (логин по умолчанию `admin`).
   Выберите функцию `setup`, нажмите **Выполнить** и разрешите доступ (Google спросит один раз).
4. **Начать развёртывание → Новое развёртывание → Веб-приложение**:
   - Выполнять от имени: **Меня**
   - У кого есть доступ: **Все**
   Нажмите «Развернуть» и скопируйте **URL веб-приложения** (оканчивается на `/exec`).
5. Вставьте URL в `config.js` в поле `api: "…"` и запушьте в git.
6. Админка: `https://www.adrenalinefest.uz/admin`: логин и пароль из шага 3.

Токен бота в скрипт вписывать не нужно: Telegram-сообщение с номером отправляет сам сайт.
Если меняете код `Code.gs`, делайте **Развёртывание → Управление → Изменить → Новая версия**: URL останется прежним.
