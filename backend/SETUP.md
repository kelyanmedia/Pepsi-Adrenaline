# Подключение заявок и админки (5 минут, один раз)

Заявки сохраняются в Google Таблицу, получают номер участника, уходят в Telegram-группу,
а админка (`admin.html`) показывает их в реальном времени и выгружает в Excel.

1. Создайте новую Google Таблицу (sheets.new), назовите «Участники Cyber Fest».
2. **Расширения → Apps Script**. Удалите всё, вставьте код из `backend/Code.gs`.
3. В функции `setup()` впишите свой пароль админки и токен бота (логин по умолчанию `admin`).
   Выберите функцию `setup` и нажмите **Выполнить** → разрешите доступ (Google попросит один раз).
4. **Начать развёртывание → Новое развёртывание → Веб-приложение**:
   - Выполнять от имени: **Меня**
   - У кого есть доступ: **Все**
   Нажмите «Развернуть» и скопируйте **URL веб-приложения** (оканчивается на `/exec`).
5. Откройте `config.js` в проекте и вставьте URL в `api: "…"`. Запушьте в git.
6. Админка: `https://ВАШ-ДОМЕН/admin.html` — логин и пароль из шага 3.

После `setup()` пароль и токен можно стереть из редактора: они сохранены в «Свойствах скрипта».

Если меняете код `Code.gs`, делайте **Развёртывание → Управление → Изменить → Новая версия**, URL останется прежним.
